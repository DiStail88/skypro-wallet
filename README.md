Skypro.Wallet
Суть приложения заключается в хранение записей расходов и последующего его анализа
Приложение способен: 1. добавлять новые расходы 2. удалять ненужные расходы 3. предоставлять пользователю график его расходов за нужный период
Для запуска нужно прописать в "TERMINAL" "npm run dev" и перейти по ссылке, зарегистрироваться, войти и можно пользоваться
